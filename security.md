# Security Disclaimer

## Intended Users of this Repository
This repository is intended for the student user (myself) and the professor or teaching assistant viewing and grading the work.

## Assessment of Risk of Security Threats
This repository has no specific rules restricting who can commit or submit pull requests beyond the permissions provided by GitHub. 
The overall security risk is relatively low because this repository is used for educational purposes and is not intended for public use. 

## Security
Beyond the two-step authentication of my GitHub account, I have not implemented any additional security measures.

I rely primarily on GitHub's built-in security features to protect the repository from unauthorized access. Since I am the primary contributor and the repository is only being used for coursework, I do not believe more advanced security measures are necessary at this time.

However, I recognize that two-factor authentication and repository privacy do not eliminate all potential security risks. I will avoid committing sensitive information such as passwords, API keys, access tokens, and other credentials. I will also review any external code or dependencies before incorporating them into the project.
